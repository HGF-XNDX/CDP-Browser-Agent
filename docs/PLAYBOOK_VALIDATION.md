## 结果边界

这是栏目偏好和站点参数约定的受控验收。规划器回放检查单步决策，生成的动作不在回放
中执行；新任务再实际调用受控工具。未由此证明真实网站总体成功率、跨网站泛化、
长周期累计收益、独立语义正确率或抵抗所有错误反思的能力。浏览器引擎的 Chromium
回归由原有自动化测试覆盖，本次真实模型场景没有启动浏览器。

默认 Python 配置关闭额外学习调用。`harness-30000.json` 开启候选学习但未注册一般网页
回放套件，因此不会自动采用未验证候选；`playbook-30000.json` 在指定示例工作流中
开启自动学习、验证和采用。应用到新网站时需提供对应的验收样例。
