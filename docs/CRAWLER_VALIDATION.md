## 已发现并修正的问题

- 初次实现遇到 Windows 长路径：已有唯一任务目录又叠加网页运行目录，导致保存失败。
  现在爬虫使用自身唯一证据目录，响应文件仍保留哈希和独立后缀。
- `v090-crawler-20260928` 的真实模型把根元素属性写成子元素选择器，反复读正文后未完成。
  增加根元素/`:scope` 语义说明、具体失败提示，以及 `web_fetch` 的 HTML 分片检查能力。
- `v090-crawler-fixed-20260928` 已产出正确记录，但验收配置没有定义逐字段 contract，
  主任务完成门禁正确拒绝成功。随后增加 equals_input 检查，保留原门禁要求。
- `v090-crawler-verified-20260928` 的 11 项文件/链路检查通过，但人工核对发现文字答复漏列 Gamma。
  增加已校验输出预览、总量及截断标记，并将三个标题是否出现在答复中加入最终 12 项检查。

这些失败记录不覆盖、不删除；最终成功仅对应 `delivery` 目录中的源码与配置。

没有动态执行爬虫脚本、分布式队列、定时调度、XPath 或附件解析。后续需要这些能力时
