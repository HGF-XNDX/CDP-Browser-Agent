## 验证边界

免密搜索可能被服务端限流或要求验证；DuckDuckGo 探测出现验证页时被识别为 challenge，
没有被当作零结果。可配置的 SearXNG/Tavily 适配器没有进行线上服务验收。
本轮没有验证所有代理类型的实际出口；SOCKS 支持来自 HTTPX 的 socks 依赖。
PAC/WPAD 脚本暂不执行。验证码、登录和动态内容仍可能需要浏览器及用户介入。
内部模型的 completed 仍是模型报告，验收脚本通过动作序列、DOM 和来源文件补充核验。
